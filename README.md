# IDU-2d

### 基本介绍 + 使用前置
IDU沙盒的2D游戏部分开发项目。\
目前可以稳定运行的版本 24H4\
下方有视频演示\
打开**IDU_24H4.py**进行运行\
**使用python 3.10+ (越新越好)运行！**\
**请安装pygame-ce而不是pygame库！**

### 游戏操作
**基础**
* 移动：w跳跃 a← d→
* 下蹲：z
* 疾跑：r
* 大跳蓄力（下蹲的时候不能疾跑）：r
* 打开背包：e
* 扔出物品：q
* 选择手中物品：鼠标滚轮/主键盘区1~9按键
* 挖掘：长按
* 放置：检测到右键按下的位置都会直接放下
* 工作台（3\*3, 4\*4, 5\*5）：打开后可以合成更多物品
* 熔炉：只有3个格子，可以煅烧物品，燃料和物品都有进度条，煅烧机制类似于mc，但比较可视化
* 箱子：打开后可以存储物品
* 配方书：打开recipe.py可以查看，配方中前一项为输入，后一项为输出。方块id在主程序中靠前的代码有加载图片，也可以到README这里的底部进行查看列表，大家可以自行对应。
* 瞄准方向：移动鼠标
* 打击牛羊：单击牛羊所在的矩形
* 吃东西：对着空白的地方单击右键。会尝试尽量一次吃饱。

有一些方块可以直接穿过（如工作台、熔炉、箱子、木头等），这不是bug，这是因为你和它们不在一个图层，这样开发是为了增强游戏效果，方便玩家操作。基础的土块、石块等是不可穿过的。

**背包 - 普通模式**
* 单击/右键 拿起/放置物品。右键只会拿起一半物品，放下1个物品。
* 滚轮：调节格子内物品数量。
* 打开选中模式：s

**背包 - 选中模式**
* 按a 平均分配到选中格子
* 按d 整顿物品（未制作）
* 按f 填充选中框到最小能补充的矩形（比如点击2\*2范围内的左上和右下，按下f整个2\*2就都选中了，自己多试试就懂了）
* 滚轮 向每个选中的格子放置/收回1个物品
* 长按拖移 选中格子
* 右键长按拖移 取消选中格子
* 单击/右键（不要拖移） 和普通模式相同
* 回到普通模式：s
